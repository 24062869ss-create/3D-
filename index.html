3Dプリンターを使う基本手順
1
利用フローを確認する
「利用フロー」タブで自分（高校生 or 中学生 or 教員）のフローを確認してください
2
3Dモデルデータを準備する
Tinkercad・Fusion 360等でSTL/3MFファイルを作成します
3
スライサーソフトで変換する
P2S → Bambu Studio　/　K1C → Creality Print　（スライサーで所要時間を事前確認してください）
4
予約を入れる（最大1か月先まで）
「予約」タブから開始時刻＋所要時間（分）を入力。初回は時間に余裕を持って設定してください
5
承認を待つ
石川真尚先生による承認後に予約が確定します。中学生は中学理科の先生と一緒に確認が必要です
6
3D佐竹によるサポートを受ける
初回は特に説明が多いため、時間にゆとりを持って参加してください
7
時間になったら「使用中」に変更（自動）
開始時刻になるとシステムが自動で「使用中」に変更します。実際に使用を開始してください
8
後片付け・使用記録を入力して終了
プレートを清掃し、「自分の予約」から完了ボタンを押して記録してください

自分の質問一覧
よくある質問（FAQ）
印刷が途中で止まってしまいました▸
プリンターの画面でエラーコードを確認してください。フィラメント切れなら補充して再開できます。それ以外は「トラブル対応」ページを確認し、解決しない場合は先生へ報告してください。
フィラメントが詰まりました▸
自己対処は危険です。「トラブル対応」ページの手順を確認してから先生に報告してください。強引に引き抜くとノズルが壊れます。
印刷物がプレートから取れません▸
完全に冷ましてから（5分以上）、プレートを軽く曲げると剥がれやすくなります。P2Sはプレートを本体から取り外して冷却すると効果的です。
印刷にどのくらい時間がかかりますか？▸
モデルの大きさや設定によって異なります。小さなパーツで15〜30分、大きなものは数時間。スライサーソフトで事前に確認できます。予約の所要時間は必ず余裕を持って入力してください。
PLA以外のフィラメントを使いたい▸
フィラメントの種類によって温度設定が異なります。必ず先生の許可を得てから使用してください。ABSは換気が必要です。K1Cはカーボンフィラメントに対応しています。
STLファイルとは何ですか？▸
3Dプリンターで使用するモデルの標準ファイル形式です。TinkercadやFusion 360からエクスポートできます。スライサーソフトに読み込んでGコードに変換してから印刷します。
予約はいつまで入れられますか？▸
最大1か月先まで予約できます。また、放課後に使えるのは2台同時までです（P2Sは1台のみ運用）。
中学生はどうやって予約しますか？▸
①まず中学理科の先生に相談・了承をもらう → ②中学理科の先生と一緒に高2・石川真尚先生まで確認・承認を取る → ③システムで予約を申請 → ④石川先生がシステム上で承認後に予約確定。
出典: Bambu Lab 公式Wiki（P2S）
ノズル詰まり（クロッグ）
フィラメントが出ない・エクストルーダー過負荷エラーが出る場合。手動押し出しを試してノズル側か確認してください。
→ 公式ノズル詰まりガイド（Bambu Lab）
ファーストレイヤーが定着しない
プレートをアルコールで清掃してベッド自動キャリブレーションを再実行してください。
→ 公式ファーストレイヤーガイド（Bambu Lab）
ホットエンド周りのフィラメント塊（ブロブ）
電源を落として冷却確認後、230℃でPLAを軟化させてから除去（高温注意）。
→ 公式ブロブ除去ガイド（Bambu Lab）
電源を入れても画面が点かない
電源スイッチのLEDパターンを確認。詳細は公式ガイドを参照してください。
→ 公式回路故障ガイド（Bambu Lab）
出典: Creality 公式Wiki（K1C）
フィラメント詰まり・送り不良
エクストルーダーハンドルを開いてフィラメントを取り出し「Auto Feed」で再試行。付属プローブで残留物を押し出す方法も有効。
→ 公式フィラメント詰まりガイド（Creality）
エラーコード 109 / 111
ヒーター・センサー系エラー。電源を落として再起動を試してください。解決しない場合は下のボタンで先生と佐竹に報告してください。
→ 公式エラーコード一覧（Creality）
カメラが認識されない
カメラのUSBケーブルを抜き差し。ファームウェアを最新版に更新。解決しない場合は先生へ。
→ 公式カメラ非認識ガイド（Creality）
Z軸の異音・ベルト弛み
Z軸ベルトの張力調整が必要です。公式ガイドを参照してください。
→ 公式ベルト調整ガイド（Creality）
🚨 異臭・煙が出た場合（緊急）
直ちに印刷を停止して電源を切り、窓を開けて換気してください。
その後、下のボタンから先生と佐竹の両方にすぐ報告してください。
プリンターが応答しない
電源ケーブルの接続を確認後、30秒待ってから再起動。自己判断でケースを開けず先生と佐竹へ報告してください。
印刷品質が悪い（層ずれ・穴・粗い表面）
スライサーの設定（レイヤー厚・温度・速度）を確認してください。フィラメントの吸湿も原因になります。解決しない場合は下のボタンで相談してください。
どうしても解決しない場合
「質問」タブから3D佐竹に相談するか、下のボタンから先生と佐竹の両方に直接メールを送ってください。エラーコードと状況を具体的に書いてください。

📋 EmailJS 設定手順
  1. emailjs.com で無料アカウントを作成（月200通まで無料）
  2. 「Email Services」→「Add New Service」→ Gmailなどを接続 → Service ID をコピー
  3. 「Email Templates」→「Create New Template」→ 以下の変数を使ったテンプレートを作成：
    To: {{to_email}}
    CC: {{cc_email}}（任意）
    Subject: {{subject}}
    Body: {{body}}
    → 保存して Template ID をコピー
  4. 「Account」→「General」→ Public Key をコピー
  5. 上の入力欄に3つのIDを貼り付けて「保存して有効化」を押す
