FAQ
印刷にどのくらい時間がかかりますか？▸
モデルの大きさや設定によって異なります。必ずスライサーで確認し、余裕を持った時間で予約してください。
中学生はどうやって予約しますか？▸
中学理科の先生に相談し、石川先生の承認を取ってから申請してください。
トラブル対応

異臭・煙が出た場合

直ちに印刷を停止し、電源を切って換気してください。その後、下のボタンで報告してください。

プリンターが応答しない▸
電源ケーブルを確認し、30秒待って再起動してください。解決しない場合は先生に報告してください。

管理者パネル

EmailJS 自動送信設定
自動送信設定が保存されています。送信に失敗する場合は Public Key をEmailJSからコピーし直してください。
EmailJS の Public Key / Service ID / Template ID を保存すると、予約申請・承認・質問・回答時に自動送信されます。未設定時はメールアプリを開きます。
  1. emailjs.com で無料アカウントを作成
  2. Email Services で Gmail/Outlook 等を接続し Service ID を取得
  3. Email Templates で To: {{to_email}}、CC: {{cc_email}}、Subject: {{subject}}、Body: {{body}} を使うテンプレートを作成
  4. Public Key、Service ID、Template ID をこの画面に入力
